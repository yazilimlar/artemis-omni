# Rainbow Botanics Data

This folder holds repository-safe Rainbow Botanics fixtures for development. It is not a
public media store and must not contain raw private photos, raw EXIF, exact private GPS,
or generated assets with unreviewed claims.

Current milestone:

- M2 data fixture for `RB-2026-00071` / *Hemerocallis fulva*
- Adaptive theme fixture for the engineering mode
- Typed exports for future page and generator work

Publication remains blocked until source, privacy, visual, and human approval gates are
complete.
