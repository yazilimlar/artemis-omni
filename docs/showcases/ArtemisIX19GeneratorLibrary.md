# ArtemisIX19 Generator Library

Status: branch implementation note
Public route: `/labs/artemisix19`

ArtemisIX19 is a public-safe copy of the attached Artemis reference lineage as a new generator surface, not a raw HTML archive. The generator converts protected workbench references into prompt, image, render, video, plot, movie, and sound packages through deterministic in-browser rules.

The route now also includes a client solution path:

1. Click 1 selects the client purpose.
2. Click 2 selects the operating terrain.
3. Click 3 locks the triangle and settles the project into one point, purpose, and meaning.

The system then updates the package categories, video prompt, convergence visual, daily teaching stream, and alternative solution matrix.

## Source Families

| Family | Source lineage | Public-safe use | Boundary |
| --- | --- | --- | --- |
| Geodesic Fabrication Shell | Goldberg dome, dowel/socket connectors, assembly labels, visual shop cards | Fabrication prompts, connector render briefs, shop-card plots | Synthetic dimensions only; no raw source HTML or unverified fabrication claims |
| Table Topology Workbench | Verified node topology and Gemini miter augmentation | Product prompts, topology plots, assembly movie beats | Prototype language only until tolerance, material, and load checks exist |
| Türkiye Atlas Story Engine | Mapbox 3D satellite atlas, polished atlas, character guides | Atlas scene prompts, storyboards, terrain confidence plots, travel sound cues | Generic planning-grade route language unless coordinates and claims are verified |
| Artemis 3D Brand Mark | Three.js brand mark and cinematic logo references | Logo render prompts, launch-film beats, audio stings | Brand-experience layer only; not product-capability proof |

## Autonomous Output Contract

Each generated package must include:

- role and mission
- two-click solution path
- triangle convergence state
- selected source family
- source signals
- audience directive
- prompt category, movie category, era category, render type, and style type
- video prompt
- asset-specific output rule
- public/private boundary
- acceptance checks
- daily essay, update, quote, cartoon prompt, question, irony, observation, public revenue idea, and 4 x 4 alternatives
- copyable prompt text
- exportable JSON manifest

## Client Solution Path

| Step | Public-safe interaction | Output effect |
| --- | --- | --- |
| Click 1 | Purpose: risk/claims, field production, cashflow/board exposure, or public learning | Defines the problem, purpose, and meaning |
| Click 2 | Terrain: contractor, executive, field, or finance | Sets audience pressure, connected records, and revenue idea |
| Click 3 | Triangle convergence | Locks the project point and updates prompt/image/video/render language |

The reasoning language is explicit: deductive contract requirements, inductive field and financial patterns, and abductive alternative-solution discovery.

## Daily Stream Boundary

The daily stream is deterministic and synthetic. It is not live news scraping, automatic public publishing, or an external AI call. It creates publishable drafts and prompts that still require human review before release.

## Current Implementation

- `data/artemisIX19.ts` defines source families, asset profiles, and the deterministic package builder.
- `components/labs/ArtemisIX19Generator.tsx` provides the client-side console, two-click path, triangle convergence, daily stream, copy action, and JSON export.
- `app/labs/artemisix19/page.tsx` publishes the new Labs route.
- `data/proofLibrary.ts`, `lib/artemis/library.ts`, `data/programCatalog.ts`, and sitemap/index pages register the route.
