# Social Media Package

## Purpose

The social package converts an approved specimen record into platform-specific assets.
Social generation must happen after review, not before evidence and privacy checks.

## Required Formats

| Platform | Asset |
| --- | --- |
| Instagram | carousel, story, square poster |
| Facebook | image post and short caption |
| LinkedIn | educational article excerpt |
| Pinterest | vertical pin |
| YouTube Shorts | thumbnail and short script |
| TikTok | cover image and short script |
| Newsletter | excerpt and download link |

## Caption Structure

1. Hook grounded in the specimen.
2. Scientific name and common names.
3. One visual or ecological fact.
4. One engineering or cultural layer.
5. Source or confidence note when needed.
6. Link to the public page after approval.

## Safety Rules

- No raw GPS.
- No private address or property-identifying details.
- No unsupported medicinal claims.
- No fake cultural mythology.
- No automated posting without human approval and account-owner authorization.
