# Hero Posters

## Purpose

Hero posters are the flagship visual asset for each specimen. They should work as web
hero media, printable plates, and high-quality social previews while remaining grounded
in the source photo set.

## Required Content

- Scientific name
- Common name set
- Specimen ID
- Spectrum designation
- Source photo reference
- Key morphology
- Bloom season
- Habitat context
- Public-safe location
- AI confidence and source status

## Poster Modes

| Mode | Description |
| --- | --- |
| Museum Poster | Elegant, image-led overview with taxonomy and key facts. |
| Scientific Plate | Cleaner herbarium-style reference with scale and labels. |
| Spectrum Poster | Emphasizes extracted palette and color engineering. |
| Atlas Poster | Connects image, map, terrain, and observation metadata. |
| Engineering Poster | Highlights geometry, roots, hydrology, and resilience. |

## Hemerocallis fulva Direction

Visual tone:

- late-summer fire,
- solar yellow core,
- copper-orange petals,
- oxidized red throat,
- meadow-green foliage,
- restrained museum label typography.

Required callouts:

- flower duration near 24 hours,
- clump-forming perennial habit,
- radial six-part floral geometry,
- public-safe observation context,
- source status for cultural and historical claims.

## Quality Rules

- Do not invent exact measurements when the photo set does not contain scale.
- Do not use raw GPS or private property identifiers in public posters.
- Label AI-generated imagery as generated or interpretive.
- Keep downloadable posters versioned by specimen ID and asset version.
