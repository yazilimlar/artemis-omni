# Blueprint Mode

## Definition

Blueprint Mode analyzes each plant as natural infrastructure. It translates morphology
into elevations, sections, callouts, measurements, symmetry overlays, and engineering
interpretation.

## Required Views

- Front elevation
- Side elevation
- Top view
- Flower cross section
- Stem section
- Leaf venation
- Root architecture when observable or sourced
- Dimension callouts
- Symmetry analysis
- Parametric geometry notes

## Engineering Categories

| Category | Examples |
| --- | --- |
| Geometry | radial symmetry, petal curvature, modular repetition |
| Structure | stem support, clump habit, load path interpretation |
| Hydrology | drought tolerance, runoff compatibility, rain garden suitability |
| Soil | stabilization, root binding, erosion control |
| Ecology | pollinator support, habitat value, companion species |
| Urban resilience | maintenance level, heat tolerance, edge planting compatibility |

## Hemerocallis fulva Blueprint Palette

```text
background: copper brown

```

## Claim Discipline

Blueprint Mode contains interpretive engineering analysis. When claims are not directly
measured, label them `interpretive`. When claims come from horticultural or ecological
sources, cite them before public release.

## Output Formats

- Web blueprint panel
- Printable blueprint poster
- SVG or canvas overlay
- Social crop
- PDF page
- Future WebGL or CAD-like exploded view
