## Conflicts and Draft-only Elements

The generated images contain useful design ideas but also draft content that must not be
treated as verified:

- inconsistent asset numbering in early concept art,
- exact-looking coordinate overlays,
- locality labels,
- AI confidence percentages,
- "AI model verified" style metadata,
- performance ratings,
- language-name panels,
- mythology and symbolism panels,
- historical timelines,
- medicinal or culinary implications,
- map-density claims,
- 3D reconstruction availability.

## Public Release Rule

Generated image text is not a source. It can inspire layout, workflow, and asset
taxonomy, but public content must be rebuilt from the specimen schema, approved source
photos, source-reviewed facts, and privacy-safe Atlas data.
