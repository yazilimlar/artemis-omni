# Vision

## Platform Definition

Rainbow Botanics is a living, adaptive botanical knowledge system. Every specimen is a
durable digital object that can combine scientific taxonomy, local field observation,
photography, GIS, cultural history, ecological relationships, engineering analysis,
visual rendering, and longitudinal monitoring.

The project should feel closer to a museum archive, observatory, and engineering atlas
than a gardening guide.

## Mission

Create a structured digital twin for each photographed plant so a user can ask:

- What do botanists call it?
- What do local residents call it?
- What did historical communities call it?
- Where does it naturally occur and where has it spread?
- How does it grow, bloom, compete, stabilize soil, and support ecology?
- How has it appeared in culture, literature, art, landscape design, or folklore?
- What can engineers learn from its geometry, root architecture, water behavior, and
  resilience?
- How has this exact specimen changed across seasons and years?

## Product Thesis

The bottleneck is not image generation quality. The bottleneck is production workflow.
Rainbow Botanics should reduce a specimen package from hours of manual work to a
repeatable review workflow:

```text
Take photos -> upload -> generate draft -> review -> approve -> preview -> publish
```

## Long-term State

Rainbow Botanics should become a botanical knowledge operating system that can later
extend to fungi, wildlife, minerals, archaeological artifacts, architecture, landscapes,
and infrastructure. The shared pattern is a structured digital twin with knowledge
layers, visual modes, atlas context, and versioned observations.

## Success Criteria for v1.0

- The standard is clear enough for Codex, Claude Code, ChatGPT, Gemini, or future AI
  systems to generate consistent outputs.
- Each record separates verified facts, historical claims, traditional claims,
  interpretive analysis, and unsourced draft content.
- The Hemerocallis reference implementation demonstrates the complete record shape.
- The pipeline is review-gated and does not publish raw private data.
