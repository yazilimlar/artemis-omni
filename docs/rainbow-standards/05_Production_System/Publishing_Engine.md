# Publishing Engine

## Purpose

The Publishing Engine converts an approved Botanical Digital Twin into public-safe
website and social outputs.

## Phase 1 Publication Target

Planned route pattern:

```text
agoraxai.com/rainbowbotanics-2026/{species-slug}
```

Examples:

```text
/rainbowbotanics-2026/hemerocallis-fulva
/rainbowbotanics-2026/rudbeckia-hirta
/rainbowbotanics-2026/echinacea-purpurea
/rainbowbotanics-2026/solidago-canadensis
```

## Publication Gates

1. Draft generated.
2. Claims reviewed.
3. Privacy reviewed.
4. Visual assets reviewed.
5. Preview build verified.
6. Human approves preview.
7. Production publish.
8. Social package prepared or scheduled.

## Output Package

An approved publish package contains:

- species page content,
- specimen JSON,
- theme JSON,
- SEO metadata,
- poster image,
- blueprint image,
- heritage image,
- PDF or printable plate,
- social captions,
- social crops,
- QA report,
- revision record.

## Preview-first Rule

All public work ships to preview first. Production and custom-domain changes require
human approval. AI agents do not manage credentials, billing, DNS, or social accounts.
