## Headline finding

**P0 — The preliminary brief's Delaware figure is stale and refuted.** It states "DE annual tax $300". Delaware's current official LLC/LP/GP tax instructions, accessed 2026-10-26, state **$400.00 per year, due on or before June 1, no annual report, no proration, $200 late penalty + 1.5%/month interest**. Any matrix, 1-year or 3-year total built on $300 understates Delaware by $100/year ($300 over 3 years, before penalties/agent fees) and must be rebuilt. Older Delaware pages still showing $300 exist on the same official domain — citing an undated Delaware FAQ without checking the current tax-instructions page is exactly how this error propagated.

## Challenger notes — decision matrix

1. **[P0] Delaware $300 → $400.** Rebuild every DE cell, annual and 3-year scenario, from the current Delaware tax-instructions page (row 2a). Add the $200 + 1.5%/month late regime and the no-proration rule (tax owed if active at any point Jan 1–Dec 31). Flag in the handoff report that the foundation brief's Delaware source citation was stale — GPT-6 should not accept any matrix that still cites the FAQ for this figure.
2. **[P0] Publication false precision.** Strike any single publication cost, statewide average, or narrow range. Honest presentation is: DOS-fixed $50 Certificate fee **plus** "newspaper charges: county = [owner input], newspapers designated by that county clerk, price only from a dated quote from those newspapers." Until the NY office county is known, the publication line is **UNPRICEABLE**, and so is every total containing it — for the NY, DE+NY, and NJ+NY options alike (row 2e: foreign qualification does not avoid it).
3. **[P0] DBA category error (row 4a).** The matrix's Great Order row must first state the fork: if Great Order is an LLC → DOS Certificate of Assumed Name, $25, no county fee; if the operator is an individual/partnership → county-clerk business certificate(s), per county, fee county-set and unquoted. Since Great Order's form is U2-UNKNOWN, the DBA row cannot be costed at all yet, and "county clerk DBA fee" must not appear as its headline.
4. **[P1] Missing recurring NY costs.** Add IT-204-LL (row 1e, revenue-banded $25–$4,500), biennial $9/2yr (also for foreign LLCs), and operating-agreement / registered-agent-equivalent / expedited / certified-copy costs as explicit scenario lines or explicit exclusions. A matrix counting only formation + annual state tax materially understates NY and DE+NY.
5. **[P1] DE formation fee and agent fee are gaps, not numbers.** Row 2c is Unverified on official sources; agent fees are private-market. Show both as UNKNOWN / market-quote-required. Do not fill them from formation-service advertising.
6. **[P1] Stacking must be visual, not footnoted.** Give DE+NY and NJ+NY each a two-state stacked table (formation state column + NY operating column + sales-tax/employer layer). A reader must be unable to take away a one-state price for a two-state plan (rows 3c, 7).
7. **[P1] "Wait / pre-registration" is not $0-risk.** Cost it honestly: $0 formation fees, but no entity shield, no Apolloa contracting capacity, operator personally/entity-directly liable, and regulated activity (food import, taxable sales) still needs a real operator + its own registrations. Do not let a $0 row win by omission.
8. **[P2] Date every figure.** Each cell needs source + access date; fees verified 2026-10-26 are a snapshot (Delaware changed within this cycle — proof that undated figures rot). Add a re-verification trigger: re-check all fees immediately before any owner filing decision.
9. **[P2] Apparel / consulting / insurance / IP have no verified figures in the packet.** Keep them as gate descriptions, not cost lines. No labelling, CPSC, licensure, insurance-premium, or trademark figure was verified against a primary source in this review — any number appearing for them in the matrix is Unverified by default.

## Challenger notes — decision & evidence gates doc

10. **[P0] Actual-operator gate before any activity, not just before formation.** Gates doc must require, for *any* pre-formation Apolloa-branded activity: named actual legal operator, that operator's formation/authority evidence, its EIN/tax classification, who signs, who is importer of record / FSVP importer / sales-tax vendor (they may be three different answers), and which books record it. Absent those, activity is **blocked**, not "booked to Apolloa pending formation" (rows 8a, 6b, 5b).
11. **[P0] Collected-tax separation gate (M2.7 carry-over).** Require: collected tax booked as liability of the actual operator from the first taxable sale; a separate collected-tax ledger / account discipline; no netting; remitter pathway recorded as U1-UNKNOWN until processor settlement + tax reports distinguish it. An upgrade of any tax-status field requires that evidence — AI narrative cannot elevate it (foundation P0-1).
12. **[P1] Missing regulatory gates to add:** (i) CBP importer-of-record / broker / bond gate, separate from FDA gates; (ii) FDA facility registration for each foreign + domestic facility that manufactures/processes/packs/holds — including any U.S. storage/packing site; (iii) per-shipment prior notice; (iv) marketplace-provider vs marketplace-seller sales-tax analysis if Apolloa sells through AgoraXAI or another platform (TB-ST-175); (v) NY + NJ employer/withholding registration if there are employees in either state; (vi) food labelling / allergen, apparel labelling/origin, and consulting licensure gates already in the brief — keep them as **activity** gates, triggered by SKU/service, not by formation date.
13. **[P1] No status upgrade on formation alone.** Filing Articles/Certificate, obtaining an EIN, opening a bank account, or filing a DBA — singly or together — upgrades **none** of: importer status, FSVP compliance, sales-tax vendor status, insurance coverage, IP ownership, or agora-to-equity. Gates doc must list the separate evidence for each upgrade, consistent with register hygiene (decisions change only on owner entry + evidenceRefs).
14. **[P2] Great Order reliance gate.** Any "transitional" use of Great Order requires its own verified formation, good standing, operating agreement authority, tax classification, and an executed (not templated) services/trade-name arrangement naming the real party (row 4c). Provisional-anchor language from D-02 is not evidence.
