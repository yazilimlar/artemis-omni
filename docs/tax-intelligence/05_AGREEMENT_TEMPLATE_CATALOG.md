**Standing warning.** Nothing in this file is an executed agreement, an offer, or legal advice. No template records a real party, date, amount, or signature. A template becomes an agreement only after (1) placeholders are completed from verified evidence, (2) counsel review, (3) owner approval, and (4) actual execution by the real parties — none of which has happened for any template here. Never backdate, never pre-sign, never describe a template as "in place."
