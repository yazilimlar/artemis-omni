# Historical Credibility Standard

## Required Fields

Every POI must have:

- title
- short description
- confidence
- evidence snippet
- source note
- layer category
- era
- date range where applicable

## Confidence Levels

### High
Secure archaeological or geographic basis.

### Medium
Plausible reconstruction from archaeological context, literary evidence, or scholarly interpretation.

### Speculative
Artist reconstruction or hypothesized feature with limited evidence.

### Uncertain
Debated or conflicting scholarly interpretation.

## Public Disclaimer

Use this baseline disclaimer:

> This scene is an interpretive historical reconstruction. Secure archaeological features are separated from plausible and speculative visualizations through confidence labels.

## KML Warning

KML anchors are useful for spatial orientation but should not be treated as final historical proof.
