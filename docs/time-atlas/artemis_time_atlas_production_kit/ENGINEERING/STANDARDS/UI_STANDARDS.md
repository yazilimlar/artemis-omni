# UI Standards — Troy V1

## Visual Identity

Tone:
- premium
- scholarly
- cinematic
- quiet
- confident

Avoid:
- fantasy game clutter
- neon sci-fi overload
- generic dashboard appearance
- unreadable labels

## Layout

- Mobile-first 9:16
- Full-screen 3D scene
- UI overlays with strong contrast
- Bottom-sheet POI cards
- Top title plaque
- Timeline on right or bottom depending screen width
- Overlay buttons near lower left

## Typography

Recommended:
- Serif or classical title font for major headings
- Clean sans-serif for body copy
- Small caps for labels and era markers

## Confidence Badges

Use clear labels:
- High
- Medium
- Speculative
- Uncertain

Do not hide uncertainty. It is part of the product's credibility.

## Copy Style

Use short, museum-label language.

Preferred:
> The citadel occupied the hill of Hisarlik and remained a major landmark across multiple settlement phases.

Avoid:
> This was definitely the exact legendary palace of Priam.
