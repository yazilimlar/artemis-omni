# ADR-005 — Mobile-First 9:16 Experience

## Status
Accepted

## Decision
The V1 experience is designed first for vertical mobile screens.

## Rationale
The product must be shareable as a 30-second vertical video and feel native to mobile discovery behavior.

## Consequences
- Desktop can show a centered vertical viewport.
- The main composition must work at 375–430px widths.
- UI must respect safe-area padding.
