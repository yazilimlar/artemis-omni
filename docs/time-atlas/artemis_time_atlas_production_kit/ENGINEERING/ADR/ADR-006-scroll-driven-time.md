# ADR-006 — Scroll-Driven Timeline

## Status
Accepted

## Decision
Vertical scroll controls era transitions and narrative progression.

## Rationale
Scroll is intuitive on mobile and makes the time concept feel physically tangible. The first version uses four era states, with only 600 BC fully active.

## Consequences
- Terrain stays fixed.
- Civilization layers fade, ghost, or activate.
- Timeline data must separate era labels from date ranges.
