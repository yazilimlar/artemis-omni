Map Engine

Primary production mode: Mapbox satellite/3D using the owner public token embedded from the attached script. Hard fallback mode: Leaflet + Esri World Imagery satellite raster tiles, so the map can render even when Mapbox/WebGL fails.
Do not ask end users for tokens. This build embeds a public pk. token from the owner script; before Squarespace/public launch, restrict it to your domain and never use an sk. secret token in the browser.
