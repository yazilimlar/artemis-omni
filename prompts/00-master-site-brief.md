# 00 — Master Site Brief (Artemis Omni)

The canonical brief. All implementation and review prompts derive from this.

## Company

Artemis Omni — an AI-first software company and intelligence platform for engineering,
construction, project controls, business operations, automation, educational tools,
AI-generated dashboards, infographics, tutorials, and interactive decision-support
systems.

## Deployment (temporary)

Test under the aGOraXai ecosystem at `artemis.agoraxai.com` (Vercel) before buying the
independent Artemis domain. `agoraxai.com` stays on Squarespace as a shell. Never build
Artemis inside Squarespace; never expose Squarespace/DNS credentials.

## Stack

Next.js App Router · TypeScript · Tailwind · shadcn-compatible · MDX · React tools/infographics
· R3F/GSAP/Lenis for selected cinematic sections only · Vercel · GitHub · Supabase later.

## Critical principle

Fast, SEO-friendly, maintainable business site with **selected** high-impact cinematic
pages. Do **not** make the whole site a heavy WebGL animation.

## Creative direction

Renaissance-inspired, Artemis/lunar symbolism, classical engineering atelier, Greek/Roman
motifs, technical artifacts (dashboards, cost curves, BIM, schedules, invoices, AI nodes),
executive luxury-tech aesthetic. Palette: dark navy, lunar black, silver, warm gold,
parchment. Serif display + technical sans. Meander borders, blueprint grids, fog, bloom.

## Sections

Home · Solutions · Labs · Academy · Tools · Case Studies · About · Contact/Pilot Request.

## Homepage hero

"The Artemis Intelligence Atelier" — executive command room × classical studio. Primary
artifact: a 5D project-control/cost-intelligence curve. Supporting: BIM fragment,
map/grid, schedule bar, cash-flow curve, AI nodes, annotations, lunar orb. First version
may use procedural/SVG/CSS instead of final GLB.

## Requirements

Static + reduced-motion fallback, lazy-load cinematic code, lightweight first load,
SEO-accessible text outside the canvas, works without WebGL, no secrets committed, docs +
prompts + ADRs present, structure ready for future AI-added content/tools/scenes.
